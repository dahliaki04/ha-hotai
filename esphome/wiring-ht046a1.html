和泰 HT046A1 除濕機 → XIAO ESP32-C3 接線圖

取代原廠 USB 型 WIFI 盒。三個零件：USB-A 公頭轉接板、BSS138 準位轉換模組、Seeed XIAO ESP32-C3。全部由除濕機的 5V 供電。

供電只能一個來源。燒錄時接 USB-C、不要插除濕機；燒好後拔掉 USB-C 再插進除濕機，之後只靠除濕機的 5V。兩邊同時接會把 5V 倒灌回機板。
USB 腳位認轉接板上的絲印，不要靠位置猜。轉接板會印 VBUS / D− / D+ / GND。剪 USB 線的話：紅＝5V、黑＝GND、白＝D−、綠＝D+。

第一次開機怎麼判斷成功

  1. 先只接 USB-C 燒錄 hotai-dehumidifier.yaml，確認 HA 出現「和泰除濕機」裝置。
  2. 拔 USB-C，拔除濕機的原廠 WIFI 盒，把 XIAO 插上。
  3. 看 ESPHome log：韌體開機會自動送登錄封包 06 00 00 FF FF ＋校驗。
  4. text sensor SA Model 顯示 HT046A1、SA Services 有內容 → 完成。
  5. 沒有任何回應 → 對調 USB pin 2 和 pin 3 那兩條線再試一次（這是最常見的錯）。
